# Signed distance function for a star

Signed distance functions (sdf) are an extremely powerful and flexible way of thinking about objects and the zones around them in two or three dimensions. They're also ridiculously easy once a certain amount of groundwork has been laid. But as they may also represent something of a paradigm shift, it's worth spending a little time getting your head around them. And not exclusively from the resource I'm providing here - I'm still learning myself!

My introduction to sdf was this YouTube video: [Building Shapes with Math | An introduction to signed distance functions](https://www.youtube.com/watch?v=Ow9JDz_qYpw)

Because we perform the same calculation at every point in space we consider, this parallelizes incredibly well, and can run on your GPU (the graphics processing unit on your computer's graphics card). But that's not what I'm going to do here. This is just going to be plain p5 JavaScript running on the CPU.

To move to the GPU, consider learning GLSL (the OpenGL Shading Language), which will get your content on the web, thus complimenting JavaScript nicely. Here's an introduction to using sdf in GLSL

[https://iquilezles.org/articles/distfunctions2d/](https://iquilezles.org/articles/distfunctions2d/)

It has a more efficient function for a six pointed star, but the derivation is not clear, so I'm going to construct one from line segments.

On your local system, [gpu.js](https://www.npmjs.com/package/gpu.js) is also a very interesting option, as it automatically transpiles simple JavaScript functions into shader language and compiles them so they run on your GPU.

## My p5 implementation

First we need a bit of setup, and a simple color scheme to help us visualize an sdf.

# %%--- [javascript]
# properties:
#   top_hidden: true
#   run_on_load: true
# ---%%
var p5WithCleanup = (sketch, text) => {
    if (!window.sketches) {
        window.sketches = {};
    }

    if (window.sketches[text]) {
        window.sketches[text].remove();
    }

    const matchedElements = Array.from(
        document.querySelectorAll('.cell-bottom'),
    );

    const matchedElement = matchedElements.find(
        (elm) => elm.parentElement.textContent.split(text).length > 1,
    );

    if (!matchedElement) {
        throw new Error(`p5WithCleanup: text not found '${text}'`);
    }

    const p5Instance = new p5(sketch, matchedElement);
    window.sketches[text] = p5Instance;
    return p5Instance;
};

# %%--- [javascript]
# properties:
#   run_on_load: true
# ---%%
await import('/p5-notebook/lib/p5/lib/p5.js');

var notImplemented = () => {
    throw new Error('Not implemented');
};

var createVector = notImplemented;
var map = notImplemented;
var constrain = notImplemented;

var mapToRainbowColor = (p, signedDistance) => {
    return p.color(
        Math.abs(signedDistance * 20) % 255,
        signedDistance > 0 ? 100 : 50,
        signedDistance > 0 ? 100 : 50,
    );
};

# %% [markdown]
Now we need a way to render an sdf in a p5 sketch

# %%--- [javascript]
# properties:
#   run_on_load: true
# ---%%
var createSetupFunction = (p, sdf, mapToColor) => () => {
    createVector = p.createVector;
    map = p.map;
    constrain = p.constrain;

    p.createCanvas(300, 300);
    p.colorMode(p.HSB);

    for (var x = 0; x < p.width; ++x) {
        for (var y = 0; y < p.height; ++y) {
            var signedDistance = sdf(p.createVector(x, y));
            p.stroke(mapToColor(p, signedDistance));
            p.line(x, y, x, y); // This is weird but Firefox does not like p.point
        }
    }
};

# %% [markdown]
Define some simple familiar transformations - scale, translate, and rotate - on an sdf function. Actually we have to apply the inverse transformation to the sdf to get the desired result. These are also known as affine transformations, and can be elegantly and efficient represented by a matrix. I intentionally haven't captured the fully generality here. In particular I want all scale operations have a 1:1 aspect ratio so that scaling the signed distance is trivial.

# %%--- [javascript]
# properties:
#   run_on_load: true
# ---%%
var createScale = (sdf, factor) => (vec) => {
    var signedDistance = sdf(vec.copy().div(factor));
    return signedDistance * factor;
};

var createTranslate = (sdf, translationVec) => (vec) => {
    return sdf(vec.copy().sub(translationVec));
};

var createRotate = (sdf, angle) => {
    var cos = Math.cos(angle);
    var sin = Math.sin(angle);

    return ({ x, y }) => {
        return sdf(createVector(x * cos - y * sin, x * sin + y * cos));
    };
};

# %% [markdown]
Now let's define a line segment.

# %%--- [javascript]
# properties:
#   run_on_load: true
# ---%%
var unitSegment = (vec) => {
    var unitVector = createVector(1, 0);
    var width = constrain(vec.x, -0.5, 0.5);
    var result = vec.copy().sub(unitVector.mult(width)).mag();
    return vec.y >= 0 ? -result : result;
};

var lineSegmentSketch = (p) => {
    var scaleFactor = 100;
    var sdf = createTranslate(
        createScale(unitSegment, scaleFactor),
        p.createVector(150, 150),
    );
    p.setup = createSetupFunction(p, sdf, mapToRainbowColor);
};

p5WithCleanup(lineSegmentSketch, 'lineSegmentSketch');

# %% [markdown]
This is an improper sdf, but will become well behaved once we chain line segments to form a closed polygon. So let's go ahead and define a triangle.

# %%--- [javascript]
# properties:
#   run_on_load: true
# ---%%
var createRegularUnitTriangle = () => {
    var angle = (2 * Math.PI) / 3;
    var height = Math.sqrt(3) / 2;
    var thirdHeight = height / 3;

    var sdfs = [0, 1, 2].map((index) => {
        return createTranslate(
            createRotate(unitSegment, index * angle + Math.PI),
            createVector(0, thirdHeight).rotate(-index * angle),
        );
    });

    return (vec) => {
        var sides = sdfs.map((sdf) => sdf(vec));
        return Math.max(...sides);
    };
};

var triangleSketch = (p) => {
    var scaleFactor = 100;
    var sdf = createTranslate(
        createScale(createRegularUnitTriangle(), scaleFactor),
        p.createVector(150, 150),
    );
    p.setup = createSetupFunction(p, sdf, mapToRainbowColor);
};

p5WithCleanup(triangleSketch, 'triangleSketch');
